# Thailand My Car - Инвестиционная платформа

Это полноценное веб-приложение, представляющее собой концепт инвестиционной платформы "Thailand My Car".

## О проекте

Приложение состоит из двух основных частей:

*   **Frontend:** Пользовательский интерфейс, разработанный на React с использованием Vite. Он обеспечивает богатый и отзывчивый пользовательский опыт.
*   **Backend:** Серверная часть на Node.js с использованием Express.js, отвечающая за бизнес-логику, API и взаимодействие с базой данных PostgreSQL.

Проект полностью контейнеризирован с помощью Docker для удобства развертывания и масштабирования.

## Технологический стек

### Frontend

*   **React:** Библиотека для создания пользовательских интерфейсов.
*   **Vite:** Инструмент для быстрой сборки и разработки.
*   **Radix UI:** Набор низкоуровневых UI-компонентов для создания доступных и настраиваемых дизайн-систем.
*   **ethers.js:** Библиотека для взаимодействия с блокчейном Ethereum.

### Backend

*   **Node.js:** Среда выполнения JavaScript на стороне сервера.
*   **Express.js:** Минималистичный и гибкий веб-фреймворк для Node.js.
*   **PostgreSQL:** Мощная объектно-реляционная система баз данных.
*   **bcryptjs:** Библиотека для хеширования паролей.
*   **jsonwebtoken:** Реализация JSON Web Tokens для аутентификации.

### Развертывание

*   **Docker & Docker Compose:** Для контейнеризации и оркестрации приложения.
*   **Nginx:** В качестве обратного прокси-сервера.

## Локальный запуск для разработки

### Предварительные требования

*   [Node.js](https://nodejs.org/) (версия 18.x или выше)
*   [Docker](https://www.docker.com/) и [Docker Compose](https://docs.docker.com/compose/)

### Запуск Backend

1.  Перейдите в директорию `backend`:
    ```bash
    cd backend
    ```
2.  Установите зависимости:
    ```bash
    npm install
    ```
3.  Запустите сервер для разработки:
    ```bash
    npm run dev
    ```

### Запуск Frontend

1.  В новом окне терминала перейдите в корневую директорию проекта.
2.  Установите зависимости:
    ```bash
    npm install
    ```
3.  Запустите сервер для разработки:
    ```bash
    npm run dev
    ```

## Развертывание на сервере

Для развертывания приложения на VPS (Virtual Private Server) следуйте подробным инструкциям в следующих файлах:

*   **[QUICK-START.md](./QUICK-START.md):** Руководство для быстрой установки и запуска за 5 минут.
*   **[VPS-DEPLOYMENT.md](./VPS-DEPLOYMENT.md):** Полное пошаговое руководство по развертыванию, включая настройку SSL и домена.
