### 2. Исправление деплоя

#### Проблема:
Сайт https://saturway.space/ был недоступен (ERR_CONNECTION_REFUSED)

#### Причина:
Контейнер был запущен неправильно:
- Использовался `docker run nginx:alpine` вместо `docker-compose`
- Порт 3000 вместо 80/443
- Отсутствовал SSL
- Не было правильного nginx.conf

#### Решение:
1. Пересборка через `docker-compose build --no-cache`
2. Запуск через `docker-compose up -d`
3. Подключение к сети `thailand-network` для связи с backend
4. Перезапуск контейнера

#### Архитектура:
```
saturway.space (45.12.135.240)
├── thailand-my-car (nginx) → порты 80, 443 (SSL)
│   ├── / → landing page
│   ├── /thailand-my-car/ → платформа
│   ├── /thailand-my-car_testnet/ → тестовая версия
│   └── /api/ → проксирование на backend
├── thailand-backend (Node.js) → порт 3001
└── thailand-postgres (PostgreSQL) → порт 5432
```

### 8. Исправление мобильного хедера

#### Проблема:
На мобильных устройствах бургер-меню не помещалось на экране из-за слишком большого количества элементов в хедере (логотип, название, переключатель языка, переключатель темы, кнопка Connect).

#### Решение:
Переключатели языка и темы перенесены в бургер-меню на мобильной версии:

1. **Переключатель языка (RU/EN)**:
   - Скрыт в хедере на мобильных: обёрнут в `<div className="hidden lg:block">`
   - Добавлен в бургер-меню

2. **Переключатель темы (светлая/тёмная)**:
   - Скрыт в хедере на мобильных: `className="hidden lg:flex"`
   - Добавлен в бургер-меню с текстом "Светлая тема" / "Тёмная тема"

#### Изменённый файл:
`src/components/thailand/ThailandHeader.tsx`

#### Результат:
- Бургер-меню теперь видно на мобильных устройствах
- При открытии бургер-меню доступны все функции: навигация, смена языка, смена темы

### 10. Google/Apple/Email авторизация

Добавлена возможность входа через социальные сети для инвесторов без крипто-кошелька.

#### Предпосылка:
Некоторые инвесторы переводят средства банковским переводом или наличными. Им нужен аккаунт для просмотра dashboard, но не нужен крипто-кошелёк.

#### Реализация:
Используется **Reown AppKit** (бывший WalletConnect Web3Modal) с включёнными социальными провайдерами.

#### Изменения в `src/config/web3modal.ts`:

```typescript
// Было:
features: {
  email: false,
  socials: false,
  onramp: false,
  swaps: false,
}

// Стало:
features: {
  email: true,
  socials: ['google', 'apple'],
  emailShowWallets: true,
  collapseWallets: true,  // Email/socials показываются первыми
  onramp: false,
  swaps: false,
}
```

#### Обновление версии AppKit:
| Было | Стало |
|------|-------|
| @reown/appkit 1.6.8 | **1.8.15** |
| @reown/appkit-adapter-ethers 1.6.8 | **1.8.15** |

#### Настройка Reown Cloud Dashboard:
- Домен `saturway.space` добавлен в Allowed Domains
- Social Login активирован для проекта

#### Порядок опций при входе:
1. 📧 Email (магическая ссылка)
2. 🔑 Google
3. 🍎 Apple
4. 💳 Кошельки (MetaMask, Trust Wallet и др.) — свёрнуты

#### Как это работает:
```
Инвестор                    Админ
   │                          │
   ├─ Платит наличкой ───────►│
   │                          │
   ├─ Входит через Google ────┤
   │                          │
   │                          ├─ Видит его в системе
   │                          ├─ Добавляет депозит
   │                          │
   ├─ Видит свой dashboard ◄──┤
   │                          │
   └─ Указывает кошелёк ──────► (только при выводе)
```

#### Преимущества:
- Инвестору не нужен MetaMask для просмотра баланса
- Вход через знакомый Google — понятно любому пользователю
- Крипто-кошелёк указывается только при выводе средств
- Упрощённый онбординг для "традиционных" инвесторов
