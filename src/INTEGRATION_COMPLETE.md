## 🚀 Как использовать

### Навигация между страницами
1. **Хедер** - используйте табы для переключения между Home/About/Invest/Dashboard/Roadmap
2. **Dashboard** - кнопка "Dashboard" в хедере
3. **Возврат** - кнопка "Вернуться на главную" в Dashboard

### Тестирование Dashboard
1. Кликните на "Dashboard" в хедере
2. Нажмите "Подключить MetaMask" (имитация)
3. Получите случайный адрес кошелька
4. Просмотрите статистику и инвестиции
5. Кликните "Вывести" на любой инвестиции
6. Изучите breakdown с комиссией
7. Используйте "Вернуться на главную" для возврата

### Подключение кошелька
- **В хедере**: Реальное подключение MetaMask (если установлен)
- **В Dashboard**: Имитация для демонстрации UI
