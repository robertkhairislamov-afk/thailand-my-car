# Thailand My Car - Структура проекта

## 🎯 Описание
Крипто-платформа для сбора инвестиций в рентал-бизнес автомобилей Toyota в Паттайе с использованием стейблкоинов (USDT, USDC).

## 🎨 Дизайн
- **Цветовая схема**: #143C50 (темный), #009696 (teal), #28B48C (зеленый), #FFC850 (золотой), #FFFAF0 (светлый)
- **Стиль**: Modern Web3 финтех с glassmorphism эффектами
- **Режимы**: Dark/Light theme

## 📁 Структура файлов

### Главные файлы
- `/App.tsx` - Главный файл приложения с навигацией и роутингом
- `/AdminApp.tsx` - Админ-панель (отдельное приложение)

### Компоненты платформы (`/components/thailand/`)
- `ThailandHeader.tsx` - Навигационный хедер с подключением MetaMask
- `Hero.tsx` - Hero секция с прогресс-баром сбора средств
- `InvestmentTiers.tsx` - Два тира инвестиций (6 мес +20% и долгосрочное)
- `AboutProject.tsx` - Информация о бизнесе, статистика, timeline

### Dashboard (`/components/`)
- `InvestorDashboard.tsx` - Личный кабинет инвестора с:
  - Экраном подключения кошелька (имитация)
  - 4 статистическими карточками
  - Списком инвестиций с прогресс-барами
  - Модальным окном вывода средств
  - Системой блокировки/разблокировки

### Дополнительные компоненты
- `ChatWidget.tsx` - AI-чат поддержки (консультант Мира)
- `/components/admin/` - Компоненты админ-панели
  - `AdminLayout.tsx` - Layout админки
  - `Dashboard.tsx` - Dashboard с аналитикой
  - `InvestmentDetail.tsx` - Детали инвестиций
  - `Messages.tsx` - Сообщения от инвесторов

## 🧭 Навигация

### Основные разделы (табы в хедере):
1. **Главная** (`home`) - Hero + AboutProject + InvestmentTiers
2. **О проекте** (`about`) - AboutProject + InvestmentTiers
3. **Инвестиции** (`invest`) - InvestmentTiers + AboutProject
4. **Dashboard** (`dashboard`) - InvestorDashboard (личный кабинет)
5. **Roadmap** (`roadmap`) - План развития проекта

### Особенности навигации:
- На странице Dashboard скрыты Header и ChatWidget
- Background image показывается только на публичных страницах
- Theme switcher (Dark/Light) в хедере
- MetaMask подключение в хедере

## 💼 Функциональность

### Подключение кошелька
- **Реальное подключение**: В ThailandHeader через MetaMask API
- **Имитация**: В InvestorDashboard генерация случайного адреса

### Инвестиции
- **Тир 1**: 6 месяцев, +20% фиксированной доходности
- **Тир 2**: Долгосрочное участие с долей прибыли + автомобиль

### Dashboard Features
- Статистика: Инвестировано / Заработано / Общий баланс / Активных
- Прогресс-бары инвестиций
- Lock/Unlock система с таймером разблокировки
- Модальное окно вывода с расчетом комиссии 5% за досрочный вывод
- Empty state для новых инвесторов

### Чат поддержки (Мира)
- Персонализированный AI-консультант
- Аватары 64px в header, 40px в сообщениях
- Автоматические приветствия
- История сообщений в localStorage

## 🎭 Админ-панель
Отдельное приложение в `/AdminApp.tsx` с:
- Dashboard с графиками и аналитикой
- Управление инвестициями
- Просмотр сообщений от инвесторов
- Responsive дизайн

## 🚀 Запуск
```bash
# Основная платформа
npm run dev

# Открыть в браузере
http://localhost:5173
```

## 📝 Технологии
- React + TypeScript
- Tailwind CSS v4
- Motion (Framer Motion)
- Lucide React (иконки)
- MetaMask Web3 API
- Recharts (для графиков в админке)

## 🔐 Архитектура
**Централизованный подход** - без смарт-контрактов:
- Средства поступают напрямую на корпоративный кошелек
- Учет инвесторов через PostgreSQL (бэкенд)
- BSC/Polygon для низких комиссий (~$0.20)
