# 🚀 Quick Start - AI Chat Widget

## 5-минутное руководство по использованию чат-виджета

---

## 📖 Для пользователей сайта

### 1. Открыть чат
Кликните на круглую кнопку 💬 в правом нижнем углу экрана.

### 2. Зарегистрироваться
```
Введите ваше имя: [Ваше имя]
Email (опционально): [your@email.com]

👇 Нажмите "Начать чат"
```

### 3. Задайте вопрос
Примеры вопросов, на которые AI ответит:

**Об инвестициях:**
- "Сколько стоит инвестиция?"
- "Какие тиры доступны?"
- "Какой минимум?"

**О доходности:**
- "Какой ROI?"
- "Сколько можно заработать?"
- "Когда получу прибыль?"

**О криптовалюте:**
- "Какую крипту принимаете?"
- "Как оплатить через MetaMask?"
- "Можно ли USDT?"

**О безопасности:**
- "Это надежно?"
- "Какие риски?"
- "Есть ли гарантии?"

**О проекте:**
- "Где находятся машины?"
- "Какие автомобили в парке?"
- "Как связаться?"

### 4. Получите ответ
AI ответит за 1-2 секунды! Продолжайте диалог сколько угодно.

### 5. Закрыть чат
Кликните ✕ в углу окна чата.

---

## 🎛️ Для администраторов

### 1. Войти в админку
```
Перейдите: http://localhost:5173/admin
```

### 2. Открыть раздел Messages
Кликните "Сообщения" в боковом меню.

### 3. Просмотр чатов
**Левая панель** - список всех чат-сессий:
- 🔴 Красный badge = новые непрочитанные
- 🟢 "Active" = активный чат
- ⚫ "Closed" = закрытый чат

**Правая панель** - переписка:
- История всех сообщений
- Аватары пользователей и бота
- Timestamps

### 4. Фильтры и поиск
**Статус:**
- "Все" - все чаты
- "Активные" - только открытые
- "Закрытые" - завершенные

**Поиск:**
```
[🔍 Поиск по имени, email, сообщениям...]
```

### 5. Ответить вручную
```
Выберите чат → Введите ответ внизу → Отправить
```
Ваш ответ перекроет AI-агента!

### 6. Закрыть чат
```
Кнопка "Закрыть чат" в header переписки
```

## 🐛 Решение проблем

### "Чат не открывается"
→ Очистите cache браузера (Ctrl+Shift+Delete)

### "Сообщения не сохраняются"
→ Проверьте что localStorage включен в браузере

### "AI не отвечает"
→ Обновите страницу (F5)

### "Админка не показывает чаты"
→ Убедитесь что пользователи уже писали в чат

### "Unread count неверный"
→ Кликните на чат чтобы пометить прочитанным

## 📊 FAQ

**Q: Можно ли удалить историю чата?**  
A: Да, очистите localStorage в Dev Tools (будет кнопка в UI)

**Q: Сколько хранится история?**  
A: До очистки localStorage (неограниченно в текущей версии)

**Q: Можно ли экспортировать чаты?**  
A: В будущей версии - да (CSV/JSON export)

**Q: Работает ли оффлайн?**  
A: Нет, требуется интернет для AI-ответов

**Q: Можно ли прикреплять файлы?**  
A: Пока нет, планируется в Phase 2

**Q: Поддерживается ли несколько языков?**  
A: Сейчас русский, английский в roadmap


```tsx
// В getAgentResponse()
if (lowerMsg.match(/ваш_паттерн/)) {
```

